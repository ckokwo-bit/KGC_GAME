

Un petit jeu de devinette en Python avec un système d'authentification (inscription + connexion). Les comptes sont sauvegardés dans un fichier JSON.

## Fonctionnalités
- Création de compte avec vérification des doublons
- Connexion sécurisée (nom + mot de passe)
- Jeu : deviner un nombre secret entre X et Y
- 5 tentatives par partie
- Rejouer sans relancer le programme
